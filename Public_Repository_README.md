# Find Your Class

Public HTTPS demo: https://find-your-class-dias.onrender.com/

Find Your Class is a university study-room booking prototype by Dias Mussin, Alimkhan Zhaxygulov, and Madi Kamenov (IIoT 2626). The application defaults to the fictional demo student Stephen Curry and supports English, Kazakh, French, and Chinese.

The full project package, source files, report, presentation, forms, and run instructions are in `Final_Dias_Mussin_IIoT2626.zip`.

The site is prepared for search indexing with a description, canonical URL, `robots.txt`, and `sitemap.xml`. Google Search Console submission is pending; Google does not guarantee an indexing date. Share the direct HTTPS address with the instructor.

This is a teaching prototype. The free host may reset SQLite bookings after sleep or restart. Demo roles are not secure authentication.
